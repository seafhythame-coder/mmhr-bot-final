# 🚀 نظام MMHR المصلح (نسخة Render)

هذه النسخة تم إصلاحها بالكامل لتعمل على **Render** دون مشاكل الـ 500 أو الـ 502.

## ✨ ما الجديد في هذه النسخة؟
1. **نظام التشغيل المرن:** السيرفر سيعمل حتى لو لم تكن قاعدة البيانات PostgreSQL جاهزة (سيستخدم ملف JSON محلي).
2. **إصلاح البوت:** تم تعديل البوت ليكون أذكى في تسجيل الدخول ورفع الملفات.
3. **تحليل العقود:** تم تحسين كود بايثون لمعالجة PDF و Word والصور.

## 🛠️ خطوات التشغيل على Render:

### 1. إعدادات البيئة (Environment Variables)
في لوحة تحكم Render، أضف المتغيرات التالية:
- `TELEGRAM_BOT_TOKEN`: توكن البوت الخاص بك.
- `API_BASE_URL`: رابط السيرفر على Render (مثلاً `https://your-app.onrender.com`).
- `JWT_SECRET`: أي كلمة سر عشوائية لتشفير الجلسات.
- `DATABASE_URL`: (اختياري) إذا أردت استخدام PostgreSQL.

### 2. الأوامر (Commands)
- **Build Command:** `npm install && pip install -r requirements.txt`
- **Start Command:** `npm start`

### 3. تشغيل البوت
البوت مدمج ويمكن تشغيله مع السيرفر أو بشكل منفصل. لتشغيلهما معاً على Render، تأكد من أن الـ Start Command هو `npm start`.

---
**ملاحظة:** إذا كنت تستخدم الخطة المجانية في Render، قد ينام السيرفر بعد فترة خمول. أول رسالة للبوت قد تتأخر قليلاً حتى يستيقظ السيرفر.
